# 英语猜词背诵器

把背单词变成「猜词游戏」：给你单词 + 词根拆解，你猜中文意思，AI 判断你猜得**有多接近**；或者反过来，给中文释义 + 词根，让你拼出单词。同时内置 630 条词根词缀本，边玩边学构词法。

既可直接在浏览器里跑（Node 本地服务），也可打包成独立桌面应用。

## 启动

```bash
npm install        # 仅需用于 Electron 桌面版；纯浏览器模式零依赖
node app/server.js
```

浏览器打开 <http://localhost:4578>。只需要 Node 18+，运行时零第三方依赖。

### 桌面版 / 打包

```bash
npm install
npm run app        # Electron 窗口模式
npm run dist       # 打包 Windows 桌面应用到 dist-app/
npm run build      # 打包 + 生成启动器
npm run pack       # 打包单文件 exe 到 dist/word-reciter.exe
```

## 两种玩法

| 模式 | 给你看 | 你要做 | 判定 |
|---|---|---|---|
| 猜词义 | 单词 + 音标 + 词根拆解 | 输入中文意思 | AI 给出 0-100 语义接近度，≥85 算答对；错了会告诉你「差多远」并给分层提示（不会直接剧透） |
| 拼单词 | 中文释义 + 词根提示 + 字母数 | 拼出英文单词 | 字母级反馈（绿=位置对，黄=字母有但位置错）+ AI 指出错在哪个词根 |

### 答对后弹出单词卡

答对（或点「看答案」）会弹出一张单词卡，内容包含：

- 单词 + 音标（可发音）、完整释义（所有词性义项）
- 词根拆解（本地库优先，拆不出来可点「AI 拆词根」）
- **例句**：优先用词库里的；词库没有就自动让 AI 补两条（中英对照），结果存进「词根资料库」长期复用
- 同根词 / 近义词 / 常用搭配
- 右上角 **☆ 星星**：点击收藏进生词本（变实心 ★），生词本可在「词库」页筛选 `★ 生词本` 查看

卡片底部三个按钮决定它什么时候再出现：

| 按钮 | 含义 |
|---|---|
| **不熟** | 明天复习 |
| **不太熟** | 3 天后复习 |
| **牢记** | 毕业，从此不再出现在队列里 |

### 3 个存档槽位

「统计」页底部有存档区，3 个槽位各能存一份**完整进度**（两个系统的学习记录 + 生词本收藏 + 复习计划）。槽位会显示存档时间与摘要（学过多少词、掌握多少、牢记多少、收藏多少），支持 读档 / 覆盖 / 删除。读档会整体替换当前进度，所以想保住现在这份，先存到别的槽位。

### 猜词义和拼单词是两套**完全独立**的系统

切模式不是"换个题面"，而是换掉一整套东西：

| | 猜词义系统 | 拼单词系统 |
|---|---|---|
| 词库 | 自己选一本（设置页/练习页） | 自己选一本，可以和上面不同 |
| 学习进度 | 单独记账 | 单独记账 |
| 今日队列 | 独立的词表 + 独立的位置 | 独立的词表 + 独立的位置 |
| 统计/复习计划 | 统计页单独看 | 统计页单独看 |

所以猜词义答到第 7 个，切去拼单词练一会儿，再切回来还是第 7 个，一点不丢；一边答对的词也不会被算成另一边会了。队列位置也会存盘，关掉浏览器再打开照样接着来。

### 防剧透（重要）

猜词游戏最忌讳 AI 顺手把答案解释出来，所以做了三层约束：

1. **提示词层**：明确禁止复述 / 翻译 / 近义改写释义，禁止「它更强调…」「核心意思是…」这类句式，并给了正反例。
2. **保险丝层**：前端拿到点评后，会把它和正确释义做最长公共子串比对，只要连续重合 ≥3 个汉字，就整段换成安全文案。AI 再顽固也漏不出来。
3. **不主动送线索**：判定结果里**不带任何提示**。想要线索必须自己点「要提示」，提示分 2 级（先给「方向」，再给「场景」），逐级变具体，但都不会报出中文释义。想从用法入手可以点「看例句」：先只给英文，想看中文得再点一次并二次确认。

拼写模式还有两道额外保护：

- **点评受限**：只能指出错在哪一段、漏了哪个字母，禁止写出完整正确拼写。
- **词根提示会自动遮蔽**：如果显示词根等于报答案（整个单词本身就是一个词根，如 limit / sign / class / fund；或单个词根片段覆盖了大半单词），词根区就会藏起来，并写清原因。猜词义模式不受影响 —— 那边词根本来就是题目的一部分。

答案只在两种情况出现：你点了「看答案」，或者已经答对。

### 词根是常驻显示的

单词卡上永远能看到词根拆解，颜色区分成分：黄=前缀、紫=词根、青=后缀、灰=没查到释义的片段。

**灰块（没释义的片段）可以点。** 点一下会自动填进下面的「片段不懂？」输入框，再点「问 AI 含义」，AI 会告诉你这个片段在构词上最接近什么含义：是某个词根的变体（如 spec/spect、cap/cep/cip），还是压根不表意的连接字母/词干残留，并给出例词。

**AI 的回答会被存进「片段档案」，下次不用再问**：查过一次的片段，结论写进 `data/roots_library.json`（跨浏览器、跨设备都在），之后：

- 单词卡上的该片段直接变成**绿色**并显示含义，不再是"点我问 AI"的灰块
- 点它一下立刻展开完整结论（来源说明 + 例词），**不发任何请求、不花 token**
- 「词根本」页面底部有「我查过的片段」专区，随时翻阅复习

省 token 的三级策略：先查本地 630 条词根表（免费）→ 再查片段档案（免费）→ 都没有才请 AI，并立刻存进档案。

## AI 配置

网页「设置」页填写接口地址 / 模型 / API Key。**密钥只存在本机的 `data/api_config.json`，不会发到任何第三方**，浏览器只与本机 localhost 通信（本地代理架构）。支持任何 OpenAI 兼容接口：DeepSeek、豆包（火山方舟）、通义千问、Kimi、智谱、OpenAI、本地 Ollama 等。

也可以直接编辑配置文件：把 `data/api_config.example.json` 复制为 `data/api_config.json` 后填入 Key。**该文件已在 `.gitignore` 中，不会被提交。**

没配 Key 也能玩：相似度改用本地字符重合度估算，拼写反馈本来就是本地算的，只是没有 AI 点评。

> **安全提示**：API Key 属于个人凭证，请勿提交到公开仓库。若已不慎泄露，请立即到对应服务商处吊销并重新生成。

## 词库

内置三本词库，原始数据来自开源项目 [kajweb/dict](https://github.com/kajweb/dict)（原始出处为有道公开单词书）：

| 词库 | 词数 |
|---|---|
| 考研英语词汇 | 4533 |
| 雅思词汇 | 3427 |
| 高中英语词汇 | 约 3500 |

转换后的数据文件在 `data/books/*.json`。想换词库：修改 `tools/build-books.js` 里的 `SOURCES`，把原始 JSONL 放到对应路径后运行

```bash
node tools/build-books.js
```

## 设计要点

- **判定逻辑**：AI 只做语义判定这件事（分数 + 是否答对 + 点评 + 不剧透的提示），拼写对错由本地算法先判，AI 只补充错因分析 —— 省 token 且更稳。
- **离线兜底**：没 Key 时本地估算相似度，游戏不中断。
- **词根资料库**：AI 拆解结果写入 `data/roots_library.json`，同一个词只请求一次。
- **JSON 容错**：AI 返回可能带代码块或废话，服务端统一用 `parseJsonSafe` 抽取。
- **零运行时依赖**：后端只用 Node 内置模块（`http`/`fs`/`path`），没有 express 之类的包袱，打包体积小。

## 隐私说明

本应用**不收集任何数据**。所有学习进度、存档、AI 配置都存放在本机 `data/` 目录下，全部网络请求只发生在你的机器与你自选的 AI 服务商之间。
